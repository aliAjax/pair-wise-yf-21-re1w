# 织补 · 手工地毯修复档案工作台

给手工地毯修复工作室使用的纹样与修复档案单页应用。替代纸卡，把产地、补线色、
破损部位、标记图和工序进度统一登记，避免对不上号。

## 功能

- **基础档案**：产地、年代、结密度（含单位）、材质、染色类型、补线色名与色值。
- **纹样局部标记图**：上传局部图（可拖拽），在图上为每个破损部位点击落标记点；
  部位用不同颜色编号，点标记可删除。
- **材料色卡**：12 种常用补线色卡 + 自定义取色；确认后才能开始补线。
  - **联动失效规则**：补线颜色或破损部位（名称 / 程度 / 描述 / 增删）一旦改动，
    色卡确认立即失效，三道工序记录清空，状态退回「待配线」并写入履历。
- **工序顺序登记**：清洗 → 补线 → 压平，不可跳步（未确认色卡时补线锁定；
  前一道没完成后一道锁定）；撤销中间工序会连带撤销其后工序。
- **修复前后照片**：分组上传、写说明、点击灯箱放大。
- **归档**：三道工序全部完成才可归档，归档后只读（可取消归档继续编辑）。
- **档案列表**：按产地筛选 + 状态筛选 + 关键词搜索，卡片显示色卡确认状态和工序进度。
- **进度留存**：所有数据（含压缩后的照片）写入浏览器 localStorage，
  关掉页面再打开进度还在；详情页用 hash 路由，刷新不丢位置。

## 本地运行

```bash
npm install
npm run dev        # http://localhost:62009
npm run build      # 生产构建
npm test           # 业务规则 + 种子数据 / 持久化测试
```

首次打开自动生成 3 条示例档案（波斯 CAR-092 修复中、安纳托利亚 CAR-117 待归档、
藏毯 CAR-138 已归档），纹样图由 canvas 程序化生成。

## 目录结构

```
src/
  types.ts                 数据模型
  App.tsx                  列表 / 筛选 + 状态管理 + localStorage 持久化
  lib/
    constants.ts           枚举、色卡、状态机 getStatus
    rules.ts               纯函数业务规则（色卡失效、工序顺序、归档条件）
    storage.ts             localStorage 读写
    pattern.ts             示例纹样图与破损斑块生成
    seed.ts                示例档案
    utils.ts               ID、时间、图片压缩
  components/
    RecordPage.tsx         档案详情 / 编辑工作台
    MarkerMap.tsx          纹样局部标记图
    PhotoGallery.tsx       修复前后照片墙
    StepDialog.tsx         工序登记弹窗
    Modal.tsx              通用弹窗
  lib/__tests__/           规则与数据测试（esbuild 打包后用 node 运行）
```

> 数据仅保存在当前浏览器，清除浏览数据会一并删除档案。
