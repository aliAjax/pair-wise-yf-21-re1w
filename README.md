# 手工地毯修复 · 纹样档案工作台

给手工地毯修复工作室使用的档案工作台，替代纸质流程卡，解决产地、补线色、破损部位对不上的问题。

## 功能

- **档案登记**：产地、年代、结密度、材质、染色类型、破损部位、补线颜色（材料色卡）、修复前后照片。
- **纹样局部标记图**：上传纹样局部照片，点击图面落标（M1、M2…），每个标记关联破损部位并填写损伤说明。
- **按产地筛选**：产地下拉（含全部已登记产地），并支持阶段筛选（待配线/待清洗/待补线/待压平/待归档/已归档）与关键词搜索。
- **色卡确认联动**：补线颜色或破损部位一经修改，材料色卡确认立即失效，档案退回「待配线」，清洗/补线/压平记录清空，需重新确认后按顺序重做。
- **工序顺序留痕**：清洗 → 补线 → 压平，必须依次记录（含完成时间与处理说明），只允许撤销最后一道。
- **归档**：三道工序全部完成、且上传修复后照片后才能归档；归档后信息锁定，可撤销归档。
- **进度持久化**：全部数据保存在浏览器 localStorage，关掉页面再打开进度仍在；支持导出 / 导入 JSON 备份（照片自动压缩）。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62009，首次打开会自动生成 4 条示例档案（含纹样局部图与不同工序阶段）。

## 技术栈

React 19 + Vite + TypeScript（无后端，纯前端本地存储）
